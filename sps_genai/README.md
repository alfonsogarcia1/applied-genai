# sps_genai

FastAPI app for Applied Generative AI. It has a bigram text generator (Module 3),
word embeddings from spaCy's `en_core_web_lg` model (Assignment 1), a CNN image
classifier trained on CIFAR10 (Assignment 2), an LSTM text generator (Module 6), and a
GAN that draws hand-written digits (Assignment 3).

## Run with Docker

```bash
docker build -t sps-genai .
docker run -p 8001:80 sps-genai
```

The API is then at http://localhost:8001 and the interactive docs are at
http://localhost:8001/docs.

## Endpoints

| Method | Path | Body | Returns |
|---|---|---|---|
| GET | `/` | | hello world |
| POST | `/generate` | `{"start_word": "bigram", "length": 10}` | generated text |
| POST | `/embedding` | `{"word": "apple"}` | the 300-dimension vector for the word |
| POST | `/similarity` | `{"word1": "apple", "word2": "banana"}` | cosine similarity of the two words |
| POST | `/classify` | an image file (form field `file`) | the CIFAR10 class, confidence and all 10 probabilities |
| POST | `/generate_with_rnn` | `{"start_word": "monte", "length": 20}` | text generated by the LSTM |
| GET | `/generate_gan?num_images=16` | | a PNG grid of new hand-written digits (1 to 64 of them) |

`/embedding` and `/similarity` return 404 if a word isn't in the model's vocabulary.
`/classify` returns 400 if the file isn't an image.
`/generate_with_rnn` returns 404 if the start word isn't in the LSTM's vocabulary and 422
if `length` isn't between 1 and 500.

```bash
curl -X POST http://localhost:8001/embedding \
  -H "Content-Type: application/json" \
  -d '{"word": "apple"}'
```

```bash
curl -X POST http://localhost:8001/classify -F "file=@cat.jpg"
```

```bash
curl -o digits.png "http://localhost:8001/generate_gan?num_images=16"
```

Or open http://localhost:8001/generate_gan in a browser to see the digits.

## Image classifier (Assignment 2)

`helper_lib/` holds the reusable PyTorch code: data loading, models, training and evaluation.
The classifier is `CNN64` in `helper_lib/model.py`:

| Layer | Output shape |
|---|---|
| Input RGB image | 3 x 64 x 64 |
| Conv2d 16 filters, 3x3, stride 1, padding 1 + ReLU | 16 x 64 x 64 |
| MaxPool 2x2, stride 2 | 16 x 32 x 32 |
| Conv2d 32 filters, 3x3, stride 1, padding 1 + ReLU | 32 x 32 x 32 |
| MaxPool 2x2, stride 2 | 32 x 16 x 16 |
| Flatten | 8192 |
| Linear + ReLU | 100 |
| Linear | 10 (one per CIFAR10 class) |

CIFAR10 images are 32 x 32, so they are resized to 64 x 64 to fit the architecture.
After 10 epochs with Adam (lr 0.001, batch size 64) it gets 65.95% accuracy on the
10,000 test images (81% on the training set).
The trained weights are in `app/weights/cnn64_cifar10.pth`, so Docker doesn't need to retrain.
To train again (downloads CIFAR10 into `data/` the first time):

```bash
uv run python -m scripts.train_classifier
```

## GAN (Assignment 3)

`GAN` in `helper_lib/model.py` holds a `Generator` and a `Discriminator`:

| Generator | Output shape |
|---|---|
| Input noise vector | 100 |
| Linear, then reshape | 128 x 7 x 7 |
| ConvTranspose2d 128 -> 64, kernel 4, stride 2, padding 1 + BatchNorm + ReLU | 64 x 14 x 14 |
| ConvTranspose2d 64 -> 1, kernel 4, stride 2, padding 1 + Tanh | 1 x 28 x 28 |

| Discriminator | Output shape |
|---|---|
| Input image | 1 x 28 x 28 |
| Conv2d 1 -> 64, kernel 4, stride 2, padding 1 + LeakyReLU(0.2) | 64 x 14 x 14 |
| Conv2d 64 -> 128, kernel 4, stride 2, padding 1 + BatchNorm + LeakyReLU(0.2) | 128 x 7 x 7 |
| Flatten, Linear | 1 (real/fake score) |

It is trained on MNIST (scaled to [-1, 1] to match Tanh) with `BCEWithLogitsLoss`, which
applies the sigmoid that turns the discriminator's score into a probability. Both networks
use Adam (lr 0.0002, betas 0.5 and 0.999), batch size 128, 20 epochs. The weights are in
`app/weights/gan_mnist.pth`. To train again (downloads MNIST into `data/` the first time):

```bash
uv run python -m scripts.train_gan
```

## LSTM text generator (Module 6)

`LSTMModel` in `helper_lib/model.py` is a word-level LSTM: embedding (100) -> LSTM (128)
-> linear layer over a 10,000-word vocabulary. It was trained on *The Count of Monte Cristo*
from Project Gutenberg, predicting the next word from sequences of 30 words. The weights
and vocabulary are in `app/weights/`. To train again:

```bash
mkdir -p data/monte_cristo
curl -L -o data/monte_cristo/pg1184.txt https://www.gutenberg.org/cache/epub/1184/pg1184.txt
uv run python -m scripts.train_rnn
```
